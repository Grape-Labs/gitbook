# Directory

The Governance Directory is a comprehensive hub for exploring active DAOs on Solana that utilize the SPL Governance program. It provides real-time insights, historical context, and summary data for each DAO—making it easier for users to stay informed and engaged in the broader governance landscape.

\


Designed to support both new and experienced contributors, the directory serves as a centralized resource for discovering, monitoring, and participating in governance across the Solana ecosystem.

## 🧭 What the Directory Offers

*   Overview of Indexed DAOs

    A dynamic list of DAOs currently indexed by Grape Governance, with essential metadata and activity summaries.
*   Latest Governance Activity

    See the most recent proposals, votes, and updates across all listed DAOs in real time.
*   Treasury & Participation Metrics

    Quick-access metrics including treasury balances, token distributions, and voter engagement levels.
*   Detailed DAO Profiles

    Each DAO entry includes a summary of its governance activity, voting structure, and key metrics.
*   Interactive Table View

    A sortable, filterable table that allows users to explore and compare DAOs based on custom criteria.
*   Data Caching & Refreshing

    DAO summaries are cached for fast performance and can be refreshed automatically or manually by the Grape DAO community
